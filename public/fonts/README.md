## Newsreader

- File: `newsreader-latin-400.woff2` (19,940 bytes).
- Source: [Google Fonts upright variable TTF](https://github.com/google/fonts/blob/main/ofl/newsreader/Newsreader%5Bopsz%2Cwght%5D.ttf).
- License: `Newsreader-OFL.txt`, copied from [Google Fonts](https://github.com/google/fonts/blob/main/ofl/newsreader/OFL.txt).
- Generated with FontTools 4.64.0 and Brotli 1.2.0: instantiate `wght=400`,
  `opsz=48`; subset to available characters in `U+0000-00FF`, `U+2000-206F`,
  and `U+2197`; save as WOFF2 while retaining name and license metadata.
- Upright, fixed weight 400. The source has no `U+2197` glyph.

## IBM Plex Sans

- File: `ibm-plex-sans-latin.woff2` (40,240 bytes).
- Source: [Google Fonts CSS2](https://fonts.googleapis.com/css2?family=IBM+Plex+Sans:wght@400..600&display=swap), Latin subset.
- [Original WOFF2](https://fonts.gstatic.com/s/ibmplexsans/v23/zYXzKVElMYYaJe8bpLHnCwDKr932-G7dytD-Dmu1syxeKYbSB4Zh.woff2), copied without modification.
- License: `IBMPlexSans-OFL.txt`, copied from [Google Fonts](https://github.com/google/fonts/blob/main/ofl/ibmplexsans/OFL.txt).
- Upright, normal width. The requested CSS exposes weights 400–600; the
  delivered font retains its full variable weight axis of 100–700.
- The official Latin subset does not contain `U+2197`; symbols outside its
  character coverage use the CSS system font fallback.

Retrieved on 2026-09-06. Fonts are served locally; Google Fonts is not contacted
at runtime.
